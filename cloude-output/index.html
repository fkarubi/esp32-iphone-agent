ESP32 iPhone Agent 解説
fkarubi/esp32-iphone-agent の解説

小さな基板で、AIがiPhoneを指で操作するしくみ

1,000円台の基板をiPhoneに挿すだけで、AIが画面を見て、タップして、文字を打つ。パソコンも脱獄もいらない。その中身と使い道、導入のやり方までをまとめた。

2026年10月16日時点のリポジトリ（コミット d427a2f）をもとに作成。元の作者は onehumanbeing（Henry Yuan）さん。

01これは何？（小学生向け）

ひとことで言うと「AIに目と手をつけて、iPhoneを代わりに使ってもらう道具」。

ふつうAIは、話しかけると答えを返すだけ。iPhoneのボタンは押せない。このしくみを使うと、AIがiPhoneの画面を見て、どこを押すか考えて、本当に押すところまでやってくれる。

目画面を見る基板がiPhoneの画面をテレビのように映してもらう（画面ミラーリング）。
あたまどこを押すか考えるiPhoneのアプリが画面の写真をAIに送り、「次はここを押して」と答えをもらう。
手本当に押す基板がマウスとキーボードのふりをして、画面の矢印を動かしてクリックする。

たとえるなら、電話で道案内してくれる友だち。友だち（AI）は画面の写真を見て「右上の歯車を押して」と言う。あなたの代わりに押すのは、iPhoneに挿した小さな基板。これを「できた！」となるまでくり返す。

できること・できないこと

やりたいことできる？ひとこと
アプリを開く、ボタンを押す、スワイプするできるマウス操作でタップ・スワイプを再現
英数字を打つできるキーボードのふりをして打つ
日本語を打つまだ無理英数字だけ。日本語入力は今後の予定に入っている
横向きのアプリ（ゲームなど）まだ無理縦向きが前提
パスコード入力・Apple Pay の画面見えないiPhoneがそもそも映さない画面
画面ロック中の操作できないロックすると映像が止まる
速さゆっくり1手あたり数秒。人間よりかなり遅い

向いている人

  • 電子工作やMacの操作に抵抗がない
  • 「AIに実機を触らせる」を自分の手で試したい
  • 同じ操作を何度もくり返す用事がある

向いていない人

  • 買ってすぐ使えるアプリが欲しい（App Storeには無い）
  • 日本語入力が必要な作業をさせたい
  • 目を離して完全におまかせしたい

02AIを使う使い方（5つ）

基本は「やってほしいことを文章で入れて Start を押す」だけ。AIが画面を見ながら1手ずつ進める。

共通の流れ

アプリに指示を入れる → Start → Dynamic Islandで進み具合を見る → 終わったら「Runs」タブで1手ずつ再生して確認 → うまくいった指示は保存して次から1タップで呼び出す。

指示文の言葉

指示文はAIに渡るだけなので日本語で書ける。iPhoneに打ち込む文字だけは英数字に限られる。うまく動かないときは、指示を短く区切るか英語で試す。

AI-1

アラームをまとめて設定する（公式のデモ）

こんな場面
曜日ごとに違うアラームを何本も作るのが面倒なとき。
指示の例
Set an alarm for 8:00 AM that repeats every Monday and Tuesday, then save it
AIの動き
自分のアプリを抜けて「時計」を開く → ＋を押す → 時刻のホイールに8:00を入れる → 月・火にチェック → 保存。
使い方のコツ
1本ずつ指示すると成功しやすい。終わったら時計アプリで中身を自分の目で確認する。
AI-2

設定アプリの奥にある項目を開く・切り替える

こんな場面
「文字を大きくする」「明るさの自動調節を切る」など、どこにあるか探すのが面倒な設定。
指示の例
「設定を開いて、画面表示と明るさの文字サイズを1段大きくして」／公式例 Open Settings and go to Wi-Fi
AIの動き
ホーム画面から設定を探して開く → 項目をスクロールして探す → スイッチやスライダーを操作。
使い方のコツ
Wi-Fiは基板のホットスポットにつないでいる最中なので、Wi-Fiの接続先を変える指示はさせない（AIの目が切れる）。
AI-3

毎朝の決まった操作をボタン1つで

こんな場面
出勤前に「天気アプリで鹿児島の天気を開く」「カレンダーで今日の予定を表示」など、毎日同じ手順をふむ用事。
指示の例
「天気アプリを開いて、鹿児島の1時間ごとの予報を表示して終わって」
AIの動き
1回うまくいったら、⏺ボタン →「この実行を保存」でインテントとして登録。以後は Siri、ショートカット、ウィジェット、コントロールセンターから呼び出せる。
使い方のコツ
保存したインテントには成功率と平均時間が記録される。成功率が低いものは指示を短くする。
AI-4

お手本を見せて手順を覚えさせる

こんな場面
言葉で説明しにくい操作。たとえば店で使うアプリの「いつもの画面までの行き方」。
やり方
⏺ボタン →「Record me doing it（自分でやって見せる）」→ 自分で操作 → 停止。アプリが画面の変化から手順を書き起こし、自信のない手順は黄色で示す。直してから保存する。
AIの動き
次からは、その手順を手がかりに同じ作業をやり直す。
使い方のコツ
録画中も画面ミラーリングが必要。基板には指の動きが見えないので、ゆっくり大きく操作する。会社のアプリで使う場合は、社内のルールで自動操作が許されているかを先に確認する。
AI-5

自作アプリやWebサイトを実機で見回る（副業向け）

こんな場面
自分で作ったWebサイトやアプリが、iPhoneでちゃんと動くかを毎回確かめたいとき。
指示の例
「Safariで（自分のサイト）を開いて、お問い合わせボタンを押し、入力フォームが出るか確かめて」
AIの動き
実際の指の操作と同じ経路でボタンを押す。結果は「Runs」に残り、どこで何を押したかが絵つきで再生できる。
使い方のコツ
URLは英数字なので打ち込める。問い合わせを本当に送信させない（送信ボタンの手前で止める指示にする）。

03AIを使わない使い方（5つ）

基板は「マウス＋キーボード＋画面の受信機」なので、AI抜きでもMacから命令を送って動かせる。

先に知っておくこと

iPhoneアプリ側は全部AI前提で、AIなしのボタンは無い。ここで紹介するのは、開発用に付いている Mac のテスト道具 board_test.py を流用するやり方で、公式の使い方ではない。基板はiPhoneに挿したまま、MacからBluetoothで命令を送る。

共通の準備

06章の手順でMacにファイルを取ってきて、ターミナルでそのフォルダに移動しておく。iPhoneの ESP32 Agent アプリは上にスワイプして終了しておく（Bluetoothを取り合わないようにするため）。最初の1回、MacにBluetoothのペアリング確認が出たら許可する。

# 道具を入れる（1回だけ）
brew install uv ffmpeg
# 基板が見えるかの確認
uv run hardware/tools/board_test.py info
NO-AI-1

Macで打った英数字をiPhoneに流し込む

AIなし
こんな場面
長いパスワード、Wi-Fiのキー、URL、商品のJANコードなどをiPhoneに手で打つのが面倒なとき。
使い方
iPhoneで入力欄をタップしてカーソルを出しておき、Macで次を実行。
uv run hardware/tools/board_test.py cmd "type 4901234567894" "key enter"

英数字と記号のみ。日本語は打てない。

NO-AI-2

Macからマウスのように遠隔操作する

AIなし
こんな場面
iPhoneをスタンドに置いたまま、手を伸ばさずに操作したいとき。
使い方
iPhoneのAssistiveTouchをオンにしておく。homeで矢印を左上へ寄せ、move 横 縦で動かし、clickで押す。homescreenでホーム画面に戻る。
uv run hardware/tools/board_test.py cmd "home" "move 200 400" "click"
uv run hardware/tools/board_test.py cmd "scroll -3 0"     # 縦に3段スクロール
uv run hardware/tools/board_test.py cmd "homescreen"      # ホーム画面へ

矢印の移動量は画面の点（ピクセル）と一致しない。何回か試して目で合わせる。

NO-AI-3

iPhoneの画面をMacに保存する

AIなし
こんな場面
スタッフ向けの操作マニュアルや、トラブル報告用に画面を残したいとき。iPhoneに触らずに撮れる。
使い方
iPhoneを基板のWi-Fiにつなぎ、コントロールセンター → 画面ミラーリング →「ESP32 Agent」を選んでから実行。snapは今の画面を1枚、streamは指定秒数の動画を保存する。
uv run hardware/tools/board_test.py snap                  # → hardware/tools/out/snap.png
uv run hardware/tools/board_test.py stream --seconds 20   # → out/stream.h264（動画）
ffplay hardware/tools/out/stream.h264                    # 再生

画質は小さめ（480×1040、毎秒5コマ以下）。きれいな画像が要るならiPhone本体のスクショのほうが上。

NO-AI-4

決まった手順を命令の並びで自動化する

AIなし
こんな場面
毎回まったく同じ位置を押すだけの作業。AI代がかからない。
使い方
命令を並べて1回で流す。例はキーボード操作で「検索を開いて時計アプリを起動」。
uv run hardware/tools/board_test.py cmd "homescreen" "key cmd+space" "type clock" "key enter"

AIのように画面を見て判断しないので、通知が出たりボタンの位置が変わったりすると失敗する。見張りながら使う。

NO-AI-5

ESP32の勉強・動作確認、アプリのお試し表示

AIなし
こんな場面
電子工作の教材として、Bluetoothの速さや、基板がUSBマウスになるしくみを確かめたいとき。基板が届く前にアプリの画面だけ見たいとき。
使い方
基板をMacに挿して hid を実行すると、Macのマウス矢印が勝手に動く。bench でBluetoothの転送速度を測れる。アプリは 設定 →「Demo data」をオンにして再起動すると、基板なしで全画面を見て回れる。
uv run hardware/tools/board_test.py hid          # Macの矢印が動けば成功
uv run hardware/tools/board_test.py bench --kb 512

04しくみ

基板が「目（映像の受信）」と「手（マウス）」、iPhoneアプリが「あたま（AIとのやりとり）」を受け持つ。

役目担当中身
目基板iPhoneからAirPlayで映像を受け取り、Bluetoothでアプリへ送る。基板では映像をほどかない（H.264のまま）
手基板USBのHID（マウス・キーボード）としてiPhoneを操作。クリック＝タップ、ドラッグ＝スワイプ
あたまiPhoneアプリ映像を画像にしてAIへ送り、返ってきた1手を基板に指示。裏で動き続け、止めるのはDynamic Islandから
記録iPhoneアプリ全部の実行をiPhoneに保存。タップ位置を重ねて1手ずつ再生できる

05必要なもの・費用

基板・ケーブル・Mac・AIのAPIキーがそろえば始められる。Macは最初の準備だけで、使うときは要らない。

もの条件目安
ESP32-S3 基板Seeed Studio XIAO ESP32S3（無印・PSRAM 8MB）で動作確認済み。「Sense」「Plus」ではない方約7ドル。国内通販でおおむね1,500〜2,500円
iPhoneiOS 18以降。モバイルデータ通信が使えること手持ち
つなぐケーブルUSB-CのiPhone（15以降）は基板と直結。LightningのiPhoneは「Lightning - USBカメラアダプタ」が必要USB-C同士のケーブル数百円／アダプタは数千円
MacXcode が入ること。基板への書き込みとアプリの組み立てに使う手持ち
Apple ID無料のものでOK（7日ごとに入れ直しが要る）。有料の開発者登録なら手間が減る無料／有料は年額あり
AI（画像が読めるもの）OpenAI互換のAPIならどれでも。クラウドのAPIか、自宅のサーバー使った分だけ課金

お金の考え方

  • 最初にかかるのは基板とケーブルだけ。数千円で収まる。
  • 続けてかかるのはAI代。毎回画面の画像を送るので、文字だけのチャットより使用量が増えやすい。1回の作業が10〜30手になることもある。
  • APIの管理画面で月の上限額を必ず設定しておく（08章）。
  • iPhoneのモバイルデータも使う。画像を送るぶん、ギガが減る。

06iPhoneへの導入手順

「GitHubからファイルを取る → 基板に書き込む → アプリをiPhoneに入れる → アプリで4ステップ設定」の順。全部Macで進める。

所要時間初回は2〜3時間みておく（ダウンロード待ちが長い）
App Storeには無い自分のMacで組み立てて、自分のiPhoneに入れる方式
あなた用のリポジトリfkarubi/esp32-iphone-agent（元のプロジェクトの写し）を使う
  1. Macに道具を入れる

    App Store で Xcode を入れて、1回起動して追加の部品を入れ終える（かなり時間がかかる）。次に「ターミナル」を開いて（Spotlightで「ターミナル」と入力）、以下を順に貼りつけて実行する。

    # Homebrew（Mac用の道具箱）を入れる。入っていれば飛ばす
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
# 基板に書き込む道具と git
brew install arduino-cli git

    Homebrew の最後に「Next steps」と出たら、そこに書かれた2行もそのまま実行する。

  2. GitHubからファイルを取ってくる

    GitHubはプログラムのファイル置き場。置き場1つをリポジトリと呼び、それを自分のMacに丸ごと写すことをクローンと呼ぶ。やり方は2つ。どちらか一方でいい。

    やり方手順
    GitHub Desktop（画面で操作）GitHub Desktop を入れてサインイン → File → Clone Repository → 一覧から fkarubi/esp32-iphone-agent → 保存先を「書類」にして Clone
    ターミナル（下のコマンド）「書類」フォルダに取ってきて、そのフォルダに入る
     
    cd ~/Documents
git clone https://github.com/fkarubi/esp32-iphone-agent.git
cd esp32-iphone-agent

    以降のコマンドは、すべてこの esp32-iphone-agent フォルダの中で実行する。ターミナルを開き直したら cd ~/Documents/esp32-iphone-agent から始める。

  3. 基板にプログラムを書き込む

    基板（XIAO ESP32S3）をUSB-CケーブルでMacに挿す。基板用の部品を入れてから、付属の書き込み用スクリプトを実行する。

    # ESP32用の部品（1回だけ。数分かかる）
arduino-cli core update-index --additional-urls https://espressif.github.io/arduino-esp32/package_esp32_index.json
arduino-cli core install esp32:esp32@3.3.12 --additional-urls https://espressif.github.io/arduino-esp32/package_esp32_index.json
arduino-cli lib install "NimBLE-Arduino@2.5.1"
# 書き込み（必ずこのスクリプトで）
hardware/flash.sh
    注意

    Arduino IDE で直接書き込むと失敗する。必ず hardware/flash.sh を使う（Bluetoothの細かい設定を一緒に入れているため）。

  4. アプリの設定ファイルを作る

    見本をコピーして、テキストエディットで開く。

    cp ios/Config/Local.xcconfig.example ios/Config/Local.xcconfig
open -e ios/Config/Local.xcconfig

    開いたファイルを、次のように書き換えて保存する（無料のApple IDの場合）。

    // DEVELOPMENT_TEAM = ABCDE12345
IA_BUNDLE_ID = com.fkarubi.esp32agent
IA_ENTITLEMENTS =
IA_WIDGET_ENTITLEMENTS =
    • 1行目は先頭に // を付けて無効にする（チームはXcodeの画面で選ぶ）。
    • IA_BUNDLE_ID はアプリの名札。世界で重ならない名前にする。
    • 下の2行を空にすると、有料アカウント専用の機能（Wi-Fiへのワンタップ接続など）を外して組み立てられる。外してもWi-Fiは手でつなげば使える。
  5. iPhoneの準備をして、アプリを入れる

    iPhoneをMacにケーブルでつなぎ、「このコンピュータを信頼しますか」で信頼を押す。次にプロジェクトを開く。

    open ios/IPhoneAgent.xcodeproj
    1. Xcode → Settings → Accounts で Apple ID を追加する。
    2. 左の一覧で一番上の「IPhoneAgent」→ ターゲット「IPhoneAgent」→ Signing & Capabilities → Team で自分の名前（Personal Team）を選ぶ。ターゲット「AgentActivity」でも同じことをする。
    3. 画面上部の実行先で自分のiPhoneを選び、▶（Run）を押す。
    4. iPhoneで 設定 → プライバシーとセキュリティ → デベロッパモード をオン → 再起動。
    5. アプリを開こうとして止められたら、設定 → 一般 → VPNとデバイス管理 → 自分のApple ID → 信頼。
    6. もう一度 ▶ を押すと「ESP32 Agent」が起動する。
  6. アプリの4ステップ設定（最初の1回）

    基板をiPhoneに挿して ESP32 Agent を開くと、案内が4画面出る。各ステップはアプリが自分で確認してくれる。

    画面やること
    Plug Me In基板とBluetoothでペアリングする
    Let Me See the Screen基板のWi-Fi（ESP32Agent-xxxx）につなぐ → コントロールセンター → 画面ミラーリング →「ESP32 Agent」
    Let Me Use the Pointer設定 → アクセシビリティ → タッチ → AssistiveTouch をオン。アプリが矢印の位置合わせを自動でやる
    Give Me a BrainAIの「Base URL」とAPIキーを入れる。キーはiPhoneのキーチェーンに保存される。モデルは一覧から自動で選ばれる

    Base URL の例（OpenAI を使う場合）：

    https://api.openai.com/v1
    うまく動かすコツ

    AssistiveTouch → ポインタデバイス で「軌跡の速さ」を真ん中に、「ポインタのアニメーション」をオフにする（アプリの案内にある推奨設定）。

  7. 試しに動かす

    指示欄に「設定を開いてWi-Fiの画面へ行って」と入れて Start。Dynamic Island に動きが出れば完成。

アプリの表示は英語

アプリの画面は英語と中国語だけで、日本語の表示はまだ無い。iPhoneが日本語設定なら英語で表示される。

基板を挿す → 基板のWi-Fiにつなぐ → 画面ミラーリング → 指示して Start。

08安全・注意

AIはあなたの指で操作するのと同じ。見張って、止めるボタンをすぐ押せるようにしておく。

まず試すだけ設定01だけやる
毎日使う設定01・02
大事なアプリも触らせる全部。ただしお金・送信がからむ操作はさせない
設定 01

AI代の上限を決める

こんなとき

使い始める前に必ず。

APIの管理画面（OpenAIなら Billing → Limits）で月の上限額を設定する。キーはこのアプリ専用に1本作る。

メリット

AIがくり返し失敗しても請求が膨らまない。

デメリット

上限に達すると途中で止まる。

設定 02

お金・送信・削除はさせない

こんなとき

買い物、送金、メッセージ送信、データ削除がからむ作業。

指示文に「送信・購入・削除の直前で止めて」と書く。Apple Pay やパスコードの画面はそもそもAIに見えないので、そこで止まる。

メリット

取り返しのつかない操作を防げる。

デメリット

最後のひと押しは自分でやる手間が残る。

設定 03

使ってよいアプリかを確かめる

こんなとき

会社のアプリ、ゲーム、SNSなど他人のサービスを操作させるとき。

自分の端末とアカウント、使ってよいと許されたものだけに使う。各アプリの利用規約や社内ルールで自動操作が禁止されていないかを見る。

メリット

アカウント停止や社内トラブルを避けられる。

デメリット

使える場面が減る。

その他の注意
  • 動いている間、iPhoneのWi-Fiは基板につながっていてインターネットは使えない。通信はモバイルデータ回線。
  • アプリはiOSの非公開の仕組み（自分を裏に回す機能）を使っている。自分で組み立てて使う分には問題ないが、App Storeには出せない作り。
  • 基板のプログラムのうちAirPlay部分はGPL-3.0、それ以外はMITライセンス。配る場合はライセンスに従う。

09困ったとき

まず「基板を挿し直す → 基板のWi-Fiにつなぎ直す → 画面ミラーリングをやり直す」の順で試す。

接続が切れたときは、アプリが作業を一時停止して、同じ手順から再開してくれる。

症状原因の見当どうするか
7日たったらアプリが開かない無料Apple IDの署名期限切れiPhoneをMacにつないで Xcode の ▶ をもう一度押す
flash.sh で基板が見つからないケーブルが充電専用、または基板が書き込み待ちになっていないデータ通信できるケーブルに替える。基板の「B」ボタンを押しながら挿し直して再実行
Xcode で署名エラーTeam が未選択、またはアプリの名札が他と重複両方のターゲットで Team を選ぶ。IA_BUNDLE_ID を別の名前に変える
画面ミラーリングに「ESP32 Agent」が出ない基板のWi-FiにつながっていないWi-Fiの一覧で ESP32Agent-xxxx を選ぶ。パスワードはアプリの設定画面に出る
タップの位置がずれる矢印の位置合わせがずれたCalibrate を押す。AssistiveTouch の速さを真ん中に戻す
AIにつながらないモバイルデータがオフ、URLかキーの間違いモバイルデータ通信をオン。Base URL の末尾が /v1 になっているか見る
途中で止まる・同じ所をくり返す指示があいまい、またはAIの性能不足指示を短く分ける。画像に強いモデルに替える
Macの board_test.py が基板を見つけないiPhoneのアプリがBluetoothをつかんでいるアプリを終了する。Macの Bluetooth をオンにする

10用語集

AIエージェント
指示を受けて、自分で考えながら道具を操作して作業を進めるAI。このプロジェクトではiPhoneを操作する。
ESP32-S3
Wi-FiとBluetoothを内蔵した小さなマイコン（小型コンピュータ）。安くて電子工作でよく使われる。
画面ミラーリング
iPhoneの画面を、そのまま別の機械に映す機能。コントロールセンターから選ぶ。
AirPlay
Appleの映像・音声の無線送信のしくみ。画面ミラーリングはこれを使う。基板がAirPlayの受け手のふりをする。
HID
マウスやキーボードのように、人が操作するための機器の規格。基板はこれのふりをしてiPhoneに挿さる。
Bluetooth（BLE）
近距離の無線通信。BLEは省電力版。基板とアプリ、基板とMacはこれでやりとりする。
AssistiveTouch
iPhoneのアクセシビリティ機能。オンにするとマウスをつないだとき画面に丸い矢印が出て、クリックでタップできる。
ホットスポット
機械が自分でWi-Fiを出し、ほかの機械をつながせる機能。ここでは基板がWi-Fiを出す。
H.264
動画を小さく圧縮する方式。基板は映像をこの形式のまま、ほどかずにアプリへ送る。
OpenAI互換
OpenAIのAPIと同じ形で呼び出せること。多くのAIサービスや自宅サーバー用ソフトがこの形に合わせている。
APIキー
AIサービスを使うための合言葉。これで誰が使ったかが分かり、料金が請求される。他人に見せない。
インテント
アプリに保存した作業のこと。名前、指示文、確認項目、成功率が記録され、Siriなどから呼び出せる。
ショートカット
iPhoneの標準アプリ。決まった操作をまとめて、ボタン1つや音声で実行できる。
Dynamic Island
iPhone上部の黒い部分に出る表示。作業中の様子が出て、ここから止められる。
GitHub
プログラムのファイルを置いて公開・共有するWebサービス。変更の履歴も残る。
リポジトリ
GitHub上の1つのプロジェクトのファイル置き場。フォルダ1つ分と考えてよい。
クローン
リポジトリを自分のパソコンに丸ごと写すこと。
デベロッパモード
iPhoneで、App Store以外から自分で組み立てたアプリを動かすためのスイッチ。Xcodeでつないだあとに設定に出てくる。
GPL-3.0
ソフトのライセンスの一種。それを含むソフトを配るなら、中身（ソースコード）も同じ条件で公開する必要がある。
